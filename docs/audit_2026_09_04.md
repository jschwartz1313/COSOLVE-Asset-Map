## Application fixes

- CSV imports preserve omitted fields, require edit permission for updates, handle renames and duplicate source titles, reject malformed/invalid rows, and detect stale previews before making any changes.
- Imports preserve private sources; public search no longer matches restricted source or relationship text.
- A changed source URL clears obsolete verification and link-health metadata. Legitimate evidence URLs longer than 200 characters are supported, including history.
- Repeated polygon vertices no longer cause unrelated assets to enter a selection.
- Catalog review/enrichment updates respect archived/private records, staff decisions, assignments, deleted/annotated evidence, and correction conflicts.
- Missing source-check results are not counted as healthy.
- Source availability results can be imported without changing editorial verification or staff link decisions.
- Automatic correction history notes respect the production database's length limit; complete explanations remain in review comments. GitHub CI now uses PostgreSQL to catch database-specific failures.

The update path uses additive seeding and guarded correction groups; it does not run destructive pruning or replace the hosted database. Obsolete sources remain recoverable in history. A local pre-update database backup was retained outside the repository.

## What still needs attention

1. **Review unresolved evidence.** Blue Ridge requires a new authoritative company/capability source. Haymarket's current award is supported, but its older fully-implemented-program report needs a working replacement. Three VCU laboratory records and L3Harris SupplierNet have unresolved source-host access problems.
2. **Track announced relocations.** [Liquid Robotics plans to move headquarters and manufacturing to Maryland by the end of 2026](https://www.liquid-robotics.com/resource/liquid-robotics-relocation-jessup-maryland/). Its Virginia point must be reviewed when that move occurs. Booz Allen's announced Reston move is planned for 2027.
3. **Separate address precision from coordinate accuracy.** Dedicated fields for address evidence, coordinate method, review date, and site role would be clearer than one “Exact” label. Laboratory/production-site confirmation remains more useful than guessing another corporate-office pin.
4. **Confirm operating departments for jurisdiction awards.** A funded locality is not proof that a particular police/fire building houses its drones. These records should remain generalized until official evidence identifies the operator.
5. **Confirm operations before VIPC handoff.** The checked-in evaluation Render configuration still specifies a free database without backups; this does not establish the live account's plan. Verify the actual durable database, backup/restore process, owner accounts, and production basemap arrangement before transfer.
6. **Tighten academic relevance evidence.** Appalachian School of Law and Agora University currently have generic workforce rationales without a documented unmanned-systems connection. Review their inclusion against the project's relevance standard. Agora's current offerings extend beyond theology, so assess the current institution rather than relying on an older specialist-school label.
