# Practical facility profile review

This pass expands 24 existing profiles: 12 manufacturing/supply-chain resources and 12 testing/research resources. It adds no assets, changes no permissions, and introduces no public maintenance-date badges. No operators were contacted.

## Decision-support changes

- Identify what the resource can be used for: machining, metal additive manufacturing, maritime propulsion assembly, navigation/air-data integration, aircraft support/training, simulation, controlled-road research, coastal fieldwork, or a defined laboratory experiment.
- Name equipment and dimensions only where the operator or a primary institutional source publishes them. Keep building area, tunnel/enclosure dimensions, lifting-equipment rating, and aircraft acceptance limits separate.
- Explain project entry: the machine shop, sales/calibration contact, institutional research team, government/sponsored project route, or pilot intake. Public capability descriptions are not public booking offers.
- Preserve unknown aircraft limits, capacity, lead times, prices, current flight authority, and access requirements. Retain distinct offices, industrial sites and operating areas rather than moving map pins to convenient contact addresses.
- Correct published contacts: Fulcrum's Newport News shop, NASA FDRF facility manager, UVA coastal drone-policy specialist, Inertial Labs' VIAVI contact and UVision's current U.S. office number. An older UVision named contact is not asserted to be current.
- Wrap's existing hidden/stale PDF source decision remains untouched. The update uses the separately public HTML annual-report record rather than republishing that PDF URL.
- Existing activity announcements retain their announcement-specific citations and review dates; new capability evidence is added separately rather than substituting an unrelated service page.
