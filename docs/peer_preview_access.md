# Peer-State Preview Access

The current private preview is limited to the exact COSOLVE username `jschwartz`.
Ale and Chelsea retain Virginia access only. No passwords belong in this configuration. Accounts must also
be active staff with the existing asset-view permission; listing a username does
not grant any editing or administrator permissions.

`MULTISTATE_PUBLIC=false` keeps other-state routes unavailable to other accounts.
`MULTISTATE_PREVIEW_USERS` is the comma-separated account allowlist. It applies to
superusers as well as ordinary staff. The Render Blueprint explicitly configures
both values. Existing Virginia roles and editing remain available.

The same boundary covers state switching, APIs, directory/profile links, comparison,
saved views, admin lists and objects, related choices, history/version pages,
exports, imports, review/audit tools and duplicate scans. Cross-state deletion
dependencies cannot be disclosed or deleted by a Virginia-only administrator.
Recent-action summaries are withheld from those accounts because old log entries
may contain peer record names. Hosting/database administrators remain trusted
operators of the system.

The selector is above the map and directory filters. Other pages keep it in More.
New peer-state maps start on Street. Explicitly saved basemap choices still win;
Virginia retains its existing configured default.

Website permissions do not make source files in a public GitHub repository private.
Repository visibility must be managed separately before calling the research files
confidential or unpublished.
