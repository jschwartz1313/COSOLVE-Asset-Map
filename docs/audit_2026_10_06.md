# Asset and functionality review October 6 2026

The review checked all 555 stored assets, including all 542 publicly listed assets.
Every public profile and its API response loaded successfully. Automated URL
checks cover the complete catalog; targeted source reading supports the repairs
below. This is not a fresh editorial certification of every description,
coordinate, capability, operating approval or available facility.

## Asset checks

All asset and source records passed model validation. Every public record has
sources, a public contact route, a description and a region.
No incomplete coordinate pairs, future review dates, out-of-envelope Virginia
points, leaked internal fields or high-signal duplicate pairs were found. Shared
campus points were not treated as duplicates merely because they are co-located.

The local inventory after the guarded repairs has these remaining gaps:

- 39 assets need editorial review, including the clarified DMS expansion profile.
- 58 records have no confirmed dedicated asset website. Available articles and
  parent-organization evidence remain under Sources rather than being presented
  as a dedicated website. The previously approved website corrections were
  reapplied to the local inventory after a successful isolated release rehearsal;
  the local and hosted inventories can differ.
- 28 assets use locality-level reference points, not confirmed buildings.
- 16 records describe regional activities rather than a single mapped site.
- Two documented sites have no map point: NASA Wallops UAS Test and Integration
  Facility and Systems Planning & Analysis. No proxy pin was invented.
- Blue Ridge Defense Works retains an unresolved missing homepage and a research
  follow-up state. This does not establish that the company closed or does not exist.

The public record-by-record results are in
`data/asset_review_pass_2026_10_06.json`. The database copy used for testing and
its private records remain outside version control.

## Source repairs

Nine guarded corrections repair or improve links for Virginia Tech Drone Park,
Mission Systems Division, CTRC, HII's Hampton campus, DMS's Chesapeake facility,
Virginia State Police, Zenith Aerotech, Virginia Smart Community Testbed and
Virginia UAS. Obsolete source records remain in staff history but are no longer
presented as public evidence. Staff changes, hidden sources and manual review
decisions are protected by the existing correction rules.

Drone Park scheduling now links to the
[operator's current page](https://drones.ictas.vt.edu/dronepark.html); enclosure
dimensions retain separate
[official facility evidence](https://ictas.vt.edu/Facilities.html).
CTRC links to the
[division page identifying the center](https://nationalsecurity.vt.edu/research/msd.html),
not a different research division.

DMS's operating repair/assembly facility is distinguished from its
[announced August 2026 engine-manufacturing expansion](https://www.governor.virginia.gov/newsroom/news-releases/2026/august-releases/name-1122358-en.html).
The profile does not claim that the additional capacity has been commissioned.
HII's first-phase completion remains a historical 2021 fact, not confirmation of
current campus availability.

The final catalog URL ledger, `data/source_audit_2026_10_06.json`, covers 1,208
distinct URLs: 1,021 reachable responses, 153 blocked/rate-limited/sign-in-required
responses, 33 network/TLS failures and one missing page. The actual local database
also retains older or staff-added public source references; all 1,215 URLs in that
inventory were checked separately: 1,025 reachable, 155 inconclusive access checks,
34 transport failures and the same one missing homepage.

The checker now recognizes HTTP-success ArcGIS rate-limit payloads, human
verification pages and redirects to sign-in as inconclusive. A successful HTTP
response does not verify the asset's facts. PDF and JavaScript-only sources are
not fully extracted by this audit; blocked sources require a separate review.
The ledger preserves each URL's actual check time, rather than re-dating cached
responses. Importing it updates availability fields only, not editorial status.

## Functionality fixes

- Counter-UAS discovery includes assets classified under either the domain or
  mission, without duplicating records or bypassing other filters.
- Unmapped site records say **Not mapped**, rather than implying a usable pin.
- Regional and staff location-quality counts require both coordinates before
  counting a site/exact location.
- Related-asset API links use the same publication rules as profile pages,
  including exclusions for unrelated specialized universities.

No new public controls or decorative layout changes were added.

## Reference layers

FAA airspace and heliport snapshots were fetched and validated on October 6:
7,002 UAS Facility Map cells, 33 surface controlled-airspace features, 139 flight
constraints and 128 heliports. Geometry validity, source identity, unique
identifiers and required popup fields passed validation. MAAP outlines and
curated test-site specifications were not re-dated by this refresh.

These layers are reference information, not live NOTAMs/TFRs, operational
authorization or a guarantee of aircraft/site eligibility. See
`docs/reference-layer-maintenance.md` for the review cadence.

## Application checks

Desktop and mobile browser coverage includes search and filter reset, polygon,
rectangle and radius analysis, selection-scoped exports, saved views, report and
print layouts, layer toggling/restoration, regional comparisons, asset profiles,
login/permissions and all four appearances. The final browser run passed 143
tests; one desktop-only invocation of a mobile drawer test is intentionally skipped.
All 317 backend tests and 30 frontend unit tests passed. Application checks,
migration checks, linting and static-file collection passed. The complete release
process also succeeded against an isolated database copy; no live production
database was modified during that rehearsal.

The hosted health endpoint responded successfully during this review. The early
source sweep encountered Render's application-loading response on the MAAP
reference page; a later check reached the required sign-in normally. Local tests
do not establish hosted search performance, future uptime or third-party tile
availability. The free hosting cold-start limitation is not removed by these fixes.
